# data/assets — ассеты сцены

Holder-каталог. Сами файлы в git не попадают (`data/**` в
[`.gitignore`](../../.gitignore)), версионируются через DVC.

## Что сюда кладётся

| Файл | Что это | Состояние |
| ---- | ------- | --------- |
| `hero.glb` | Герой MVP: cel-персонаж с ригом, одна поза | **ждёт файла** |
| `proxy_figure.glb` | Болванка для проверки сцены | генерируется скриптом |

Ссылки на файлы живут в [`configs/mvp/scene.json`](../../configs/mvp/scene.json)
(герой) и `scene.proxy.json` (болванка) — рендер-скрипт путей не знает.

## Требования к герою

Из [Roadmap-MVP 4.1](../../../docs/base-plans/Roadmap-MVP.md#41-ассет) и
[ADR 0002](../../../docs/architects/adr/0002-style-comes-from-project-assets.md#последствия):

- **glTF 2.0** (`.glb`, `.gltf`) или `.vrm` — это тот же glTF с расширениями,
  штатный импортёр Blender берёт из него геометрию и скелет.
- **С ригом**, в одной готовой позе. Поза в срезе не меняется.
- **Стилизованный, но геометрически честный** — уровня игрового или
  VTuber-персонажа. Модели, воспроизводящие нарисованное аниме-лицо (глаза
  одного размера с любого ракурса, причёска не в перспективе), не годятся: они
  не сводятся между ракурсами, и гейт S3 провалится не на том, что проверяется.
- **Метры, лицом к `-Y`, корень в ступнях** — соглашение осей из
  [`worldgen/scene/schema.py`](../../worldgen/scene/schema.py). Разворот
  правится полем `rotation_euler_deg` в описании сцены, а не в рендер-скрипте.

## Болванка

`proxy_figure.glb` — **не ассет MVP**, а временная затычка: она позволяет
проверить свет, кадрирование и ракурсы до появления настоящего героя. Рига нет,
и после закрытия S0 она вместе с `configs/mvp/scene.proxy.json` удаляется.

Пересобрать:

```bash
python -c "from worldgen.render import run_blender_script; print(run_blender_script('make_proxy_asset.py', ['--out', 'data/assets/proxy_figure.glb']).returncode)"
```
