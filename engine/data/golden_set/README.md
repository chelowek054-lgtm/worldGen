# Золотой оценочный набор (holder)

Read-only набор для регресс-проверок из [плана](../../../docs/archive/detailed-implementation-plan.md),
задача **0.1**. Сами данные **не коммитятся** в git — версионируются через DVC
(`*.dvc`-указатели коммитятся, содержимое лежит в DVC-хранилище).

## Состав (заполняется в 0.1)

- 20–50 объектов (жёсткие, деформируемые, с мелкой фактурой/текстом) × 8 ракурсов.
- 10–15 мультиобъектных сцен.
- 5–10 «физических» сюжетов (падение, стопка, драпировка, погружение).

## Правила

- Набор **read-only** и **не пересекается** с обучающими источниками
  (проверка по перцептивному хешу → 0 коллизий).
- Хеш набора фиксируется в конфиге прогона; версия — через `dvc add` / `dvc status`.

> Пока это только holder-каталог (DoR, задача 0.0). Наполнение и `dvc add` — в задаче 0.1.
