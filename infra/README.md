# infra — инфраструктурные конфиги

Конфигурации сервисов веб-стека, не относящиеся напрямую к коду приложения.

```
infra/
├── nginx/
│   └── nginx.conf          # реверс-прокси: / -> frontend, /api -> backend
└── postgres/
    └── init/               # SQL, выполняемый при первой инициализации БД
        └── 01-extensions.sql
```

Здесь же со временем размещаются: TLS-сертификаты, конфиги мониторинга (Prometheus/Grafana),
манифесты для деплоя (k8s/helm), правила логирования.
