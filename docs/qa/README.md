# Документация для QA

Стратегия тестирования и артефакты контроля качества.

## Разделы

- **Тест-стратегия** — уровни тестирования (unit / integration / e2e), зоны ответственности.
- **Тест-кейсы** — сценарии проверки по фичам.
- **Чек-листы** — регрессионные и релизные чек-листы.
- **Баг-репорты** — шаблон и правила заведения дефектов.

## Где живут тесты

- Backend: `backend/tests` (`pytest`) — запуск `make test-back`.
- Frontend: `frontend` (`vitest`) — запуск `make test-front`.

## Шаблон баг-репорта

```
Заголовок:
Окружение / версия:
Шаги воспроизведения:
Ожидаемый результат:
Фактический результат:
Серьёзность / приоритет:
```
