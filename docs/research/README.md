# Исследования и концептуальные разборы (R&D)

Аналитические разборы, обзоры фронтира и концепт-проработки, на которые опираются
архитектурные решения и [план реализации](../base-plans/README.md). Это **не** спецификация
системы (она в [`architects/system/`](../architects/system/README.md)), а материал
«почему так»: гипотезы, сравнения с внешними подходами, дешёвые прототипы.

## Документы

| Документ | О чём |
| -------- | ----- |
| [ДНК объектов](object-dna.md) | Консистентность идентичности объектов в DiT/VLM без полной 3D; дешёвый прототип view-invariant «ДНК». |
| [Латентный физдвижок](latent-physics-engine.md) | Как переизобрести симуляцию как латентный переход, дистиллированный из настоящего солвера. |
| [Критический разбор World-Gen](worldgen-critical-review.md) | World-Gen на фоне фронтира мировых моделей: сильные стороны, спорные места, риски. |
| [История «железа» для нейросетей](neuro-hardware-history.md) | От рубежа XX века до вычислений-в-памяти; предпосылки аппаратного ускорения. |

## Как это связано

- Гипотезы отсюда проверяются по фазам в [base-plans](../base-plans/detailed-implementation-plan.md).
- Реализованные решения фиксируются как [ADR](../architects/adr/) и попадают в
  [спецификацию системы](../architects/system/README.md).
