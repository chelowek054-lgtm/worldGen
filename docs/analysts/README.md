# Документация для аналитиков

Требования, бизнес-логика и предметная область.

## Разделы

- **Требования** — функциональные и нефункциональные требования.
- **User stories** — пользовательские истории и сценарии.
- **Бизнес-процессы** — BPMN/диаграммы потоков.
- **Глоссарий** — единая терминология предметной области (см. ниже).
