# Документация для DevOps / SRE

Сборка, развёртывание и эксплуатация.

## Окружения

| Окружение   | Назначение                | Конфиг                                    |
| ----------- | ------------------------- | ----------------------------------------- |
| development | Локальная разработка      | `docker-compose.yml` + `*.override.yml`   |
| staging     | Предпрод, приёмка         | _добавить_                                |
| production  | Боевое                    | `docker-compose.yml` + prod-переменные    |

## Разделы

- **CI/CD** — пайплайны сборки, тестов, деплоя.
- **Секреты** — управление `.env`/vault, ротация ключей.
- **Мониторинг** — метрики, логи, алерты, дашборды.
- **Инциденты** — runbooks и постмортемы.

## Полезное

- Инфраструктурные конфиги — в [`infra/`](../../infra/README.md).
- Служебные скрипты — в [`scripts/`](../../scripts/README.md).
- Бэкапы БД — том `pgdata`; стратегию бэкапа описать здесь.
