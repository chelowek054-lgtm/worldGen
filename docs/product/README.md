# Документация для продакт-менеджеров

Продуктовое видение, планирование и метрики.

## Разделы

- **Видение** — зачем продукт существует, для кого, какую боль решает.
- **Roadmap** — планы по релизам и вехам.
- **Метрики** — ключевые продуктовые метрики (активация, retention, конверсия).
- **Приоритизация** — как принимаются решения (RICE / MoSCoW и т.п.).
