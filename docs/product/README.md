# Продукт

## Что это

Инструмент, собирающий изображения сцен, в которых персонажи и объекты остаются
собой между кадрами, ракурсами и сюжетными репликами. Пользователь приносит
своих героев и свой стиль; система отвечает за содержание — геометрию,
композицию, идентичность.

Ключевое отличие от обычного генератора картинок: одиночную красивую
иллюстрацию дешевле получить чистой диффузией. Ценность появляется там, где мир
переиспользуется — те же герои в сотне кадров и в разных сюжетных ветках.

## Требования

Зафиксированы в [Roadmap, раздел 1](../base-plans/Roadmap.md#1-требования-и-рамки-продукта).
Коротко: сохранение идентичности, воспроизведение в нужной позе и ракурсе,
инкрементальное дополнение сцены, несколько визуальных стилей, версионирование
сцены под сюжетные линии, формат выхода — изображения.

## Экономика

Разбор стоимости ([Roadmap, раздел 17](../base-plans/Roadmap.md#17-критический-разбор-вычисления-против-консистентности))
даёт нетривиальный вывод для продуктовых решений: основная стоимость лежит **не
в кадре, а в подготовке ассетов**, и она амортизируется. Экономика проекта
определяется коэффициентом переиспользования: сто кадров из одной библиотеки и
сто кадров, каждый со своим новым ассетом, — две совершенно разные экономики при
одинаковом технологическом стеке.

## Риск одинаковости работ

Если все строят из общей библиотеки, проекты сливаются. Против этого работают
четыре рычага, по убыванию силы: герои принадлежат пользователю; стиль
пользовательский; окружение модульное; параметрическая вариация ассетов.
Подробно — [Roadmap 4.8–4.12](../base-plans/Roadmap.md#4-поиск-наполнение-и-вариативность-базы).

## Открытые продуктовые вопросы

| Вопрос | Почему блокирует |
| ------ | ---------------- |
| Для кого продукт и какой сценарий использования | Без этого нельзя оценить ни нужный объём библиотеки, ни экономику. `Roadmap 1.10` |
| Кто наполняет базу ассетами и сколько стоит один ассет | Главная статья расходов, не оценена. `Roadmap 4.3` |
| Правовая сторона пользовательских загрузок | Пользователь может принести чужую интеллектуальную собственность. `Roadmap 4.7` |

Эти три — первые в очереди на решение; они определяют больше, чем любой
технический выбор.
