## Когда заводить ADR

Решение заслуживает ADR, если оно меняет границы ответственности между
подсистемами, закрывает развилку, к которой можно захотеть вернуться, или его
отмена потребует переделки уже написанного. Мелкие выборы внутри одного модуля
ADR не требуют — их место в коде и комментариях.

Формат: `NNNN-краткое-название.md`, разделы Контекст → Решение → Последствия.
Статусы: предложено / принято / отклонено / устарело / заменено ADR-XXXX.
