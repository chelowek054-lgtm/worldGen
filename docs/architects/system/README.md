# Архитектура системы World-Gen

Спецификация целевой системы — модульного нейросетевого движка генерации миров
**World-Gen**: конвейер стадий, общая шина латентных представлений и интеграция
внешних бэкбонов. Это раздел «что система есть»; обоснования «почему так» — в
[research](../../research/README.md), пошаговый путь к ней — в
[base-plans](../../base-plans/README.md).
