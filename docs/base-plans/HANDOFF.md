## 4. Ключевые решения, которые нельзя размыть

- **Blender** headless под MVP; **Godot** отложен с явным триггером возврата
  (пропускная способность рендера либо интерактивное превью). Чтобы возврат
  остался дешёвым: **сцена описывается данными, рендерер их потребляет**, логики
  сцены в рендер-скрипте нет.
- **Физика в срез не входит.** Она дорогая и отвечает за другую ось
  ([Roadmap 17.2](Roadmap.md#172-физика--самый-дорогой-компонент-не-решающий-нашу-задачу)).
  Для изображений «упал» — это поза, «разрушен» — вариант ассета.
- **Одна стилевая плоскость** (cel/аниме). Разнообразие уходит внутрь неё — в
  шкалу длины поводка, а не в набор стилей.
- **Удешевление и консистентность направлены в одну сторону**
  ([Roadmap 17.1](Roadmap.md#171-главный-вывод-дорогое-не-решает-консистентность)):
  короче поводок — и дешевле, и надёжнее. Это основной вектор оптимизации.
- **Тонкий срез целиком, потом утолщение.** Не улучшать отдельный слой, пока
  цепочка не работает от начала до конца.

**Git.** Работа идёт в worktree на ветке `claude/claude-config-files-0da536`.
`main` занят основным worktree, поэтому слияние делается через временную ветку:

```bash
git fetch origin main && git branch merge-main origin/main && git checkout merge-main && git merge --no-edit claude/claude-config-files-0da536 && git push origin merge-main:main && git checkout claude/claude-config-files-0da536 && git merge --ff-only merge-main && git push && git branch -d merge-main
```

**Известная неприятность:** git иногда подхватывает Windows-версию `ssh`
(`C:\WINDOWS\System32\OpenSSH`), которая ключ не принимает, тогда как
`/usr/bin/ssh` из Git Bash аутентифицируется нормально. Проявляется как
`Permission denied (publickey)` при флапающем соединении. Лечится повтором;
проверка — `ssh -T git@github.com`.

## 6. Первые действия

1. **Установить Blender** (решение пользователя — попросить, не ставить молча).
   Нужна версия с Cryptomatte в EEVEE и рабочим headless-режимом.
2. **Найти ассет для `S0`.** Cel-персонаж с ригом, glTF. Требование, которое
   легко упустить: персонаж должен быть стилизованным, но **геометрически
   честным** — уровня игрового или VTuber-персонажа. Модели, воспроизводящие
   нарисованное аниме-лицо (глаза одного размера с любого ракурса, причёска не
   в перспективе), в срез не годятся: они не сводятся между ракурсами, и мы
   провалимся не на том, что проверяем.
3. **Каркас `S1`** по раскладке из [Roadmap-MVP, раздел 8](Roadmap-MVP.md#8-где-это-живёт-в-коде).

Порядок 1→2 можно вести параллельно; `S1` без обоих не начать.
