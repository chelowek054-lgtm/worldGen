# Базовые планы (base plans)

Опорные планы и дорожные карты реализации нейродвижка **World-Gen**: фазированные
runbook'и с измеримыми go/no-go, из которых растут задачи в трекере.

## Документы

| Документ | О чём |
| -------- | ----- |
| [HANDOFF](HANDOFF.md) | **Точка входа.** Состояние работ, порядок чтения, устаревшие документы, состояние окружения и первые действия. Читать первым. |
| [Roadmap](Roadmap.md) | **Точка сверки.** Что решено, что продумано, но не утверждено, и что открыто. |
| [Roadmap MVP](Roadmap-MVP.md) | **Что делаем прямо сейчас.** Первый сквозной срез: один персонаж → рендер → генератор → четыре стиля (аниме, манхва, кино, гиперреализм), только изображения. Шаги S0–S7 с проверками. |
| [Подробный план реализации](detailed-implementation-plan.md) | Инженерный runbook «фото → видео»: фазы 0–6, две оси (A — консистентность идентичности, B — физическая правдоподобность), у каждого шага — проверка ✅ и ветка «если не прошло». ⚠️ Фазы 1–3 частично устарели — см. раздел 11 в [Roadmap](Roadmap.md). |
| [Статус задач](STATUS.md) | Живой трекер: статусы всех задач по фазам, текущий фокус, легенда `[ ] [~] [x] [!]`. |
| [Журнал решений](decision-log.md) | Пройденные/непройденные go/no-go гейты с числами и выводами. |

## Как читать план

- **Ось A** — консистентность идентичности (тот же объект между кадрами/ракурсами).
- **Ось B** — физическая правдоподобность (динамика, столкновения, деформации).
- Каждая фаза открывается только после прохождения своего go/no-go.
- Статусы шагов: `[ ]` не начато · `[~]` в работе · `[x]` закрыто по «Проверке».
