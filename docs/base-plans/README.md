# Планы

Точка входа в работу, дорожная карта решений, план текущего среза и журнал
пройденных гейтов.

## Документы

| Документ | О чём |
| -------- | ----- |
| [HANDOFF](HANDOFF.md) | **Читать первым.** Что делаем, порядок чтения, состояние окружения, первые действия. |
| [Roadmap](Roadmap.md) | **Точка сверки.** Все решения по системе с пометками `✅ утверждено` / `🟡 продумано` / `🔴 не решено`, критический разбор стоимости, риски. |
| [Roadmap MVP](Roadmap-MVP.md) | Что строим прямо сейчас: первый сквозной срез, шаги `S0`–`S7` с проверками. |
| [Журнал решений](decision-log.md) | Пройденные и непройденные гейты — с числами и выводом. |

## Как это связано

- Архитектура, которую собирают эти планы, описана в
  [architects/system](../architects/system/architecture.md).
- Обоснования «почему так» — в [research](../research/README.md).
- Значимые развилки фиксируются как [ADR](../architects/adr/).
- Прежний фазированный план и трекер статусов перенесены в
  [archive](../archive/README.md) — они описывают снятую парадигму.

## Рабочие правила

- **Статусы решений живут только в [Roadmap](Roadmap.md).** Дублировать их в
  других документах нельзя — разойдутся.
- Статусы шагов текущего среза — в [Roadmap-MVP](Roadmap-MVP.md),
  формат `[ ]` не начато · `[~]` в работе · `[x]` закрыто по «Проверке».
- Каждый закрытый гейт — запись в [журнал решений](decision-log.md) с числами,
  а не с впечатлениями.
