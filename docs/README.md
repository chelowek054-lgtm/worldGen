## Важное про архив

В августе 2026 система сменила парадигму. Документы, описывавшие прежний подход,
перенесены в [archive/](archive/README.md) целиком — чтобы актуальные разделы
можно было читать буквально, без оговорок «а вот это уже не так».

Если вы нашли противоречие между документом из `archive/` и любым другим —
прав второй.

## Соглашения

- Формат — Markdown. Диаграммы — Mermaid прямо в тексте.
- Значимые архитектурные решения — отдельными [ADR](architects/adr/).
- Пройденные и непройденные гейты — в [журнале решений](base-plans/decision-log.md)
  с числами.
- Статусы решений (`✅` / `🟡` / `🔴`) живут только в [Roadmap](base-plans/Roadmap.md),
  чтобы не расходились между документами.
