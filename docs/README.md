# Документация onlineAtelier

Документация разделена по ролям. Каждый раздел — точка входа для соответствующей команды.

| Раздел                            | Для кого                        | Содержание                                             |
| --------------------------------- | ------------------------------- | ------------------------------------------------------ |
| [analysts/](analysts/README.md)     | Аналитики                       | Требования, user stories, бизнес-процессы, глоссарий   |
| [product/](product/README.md)       | Продакт-менеджеры               | Видение, roadmap, метрики, приоритеты                  |
| [architects/](architects/README.md) | Архитекторы                     | C4-модель, ADR, интеграции, нефункциональные требования|
| [developers/](developers/README.md) | Разработчики                    | Онбординг, конвенции кода, API, гайды по фичам         |
| [devops/](devops/README.md)         | DevOps / SRE                    | CI/CD, окружения, деплой, мониторинг, инциденты        |
| [qa/](qa/README.md)                 | Тестировщики                    | Тест-стратегия, чек-листы, тест-кейсы, баг-репорты     |

### Предметные разделы World-Gen

Помимо ролевых точек входа, документация содержит сквозные разделы по самому движку:

| Раздел                                              | Содержание                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| [architects/system/](architects/system/README.md)   | Спецификация системы: конвейер World-Gen, общая шина латентов, интеграция FLUX.2 [klein] / DINOv3 |
| [research/](research/README.md)                     | R&D-разборы и концепт-проработки: ДНК объектов, латентный физдвижок, критический разбор, история «железа» |
| [base-plans/](base-plans/README.md)                 | Опорные планы реализации: фазированный runbook «фото → видео» (оси A/B, go/no-go) |

## Соглашения

- Формат — Markdown (`.md`).
- Диаграммы — через Mermaid прямо в `.md` либо ссылкой на исходник.
- Архитектурные решения фиксируются как ADR в `architects/adr/`.
