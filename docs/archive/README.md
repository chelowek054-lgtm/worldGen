## Что из архива всё ещё действует

Не всё в этих документах ошибочно — заменены их **выводы**, а не весь материал:

- **Разделение осей A (консистентность) и B (физика)** и требование мерить их
  раздельно — действует, перенесено в [Roadmap 10.1](../base-plans/Roadmap.md#10-метрики-и-проверки).
- **Дисциплина go/no-go гейтов** с проверкой на каждом шаге — действует, в том
  же виде применяется в [Roadmap-MVP](../base-plans/Roadmap-MVP.md).
- **Приложения детального плана** (метрики, датасеты, репозитории) — остаются
  полезным справочником, хотя часть позиций устарела.
