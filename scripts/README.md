# scripts — вспомогательные скрипты

Одноразовые и служебные скрипты для разработки и эксплуатации.

| Скрипт          | Назначение                                         |
| --------------- | -------------------------------------------------- |
| `bootstrap.sh`  | Первичная настройка: .env, сборка, запуск, миграции|

Сюда добавляются: `seed.sh` (наполнение тестовыми данными), `backup.sh` (бэкап БД),
`restore.sh`, скрипты релиза и т.п.
